最後更新：2026-11-09

適用範圍

ECPay Mail Agent（以下稱本工具）是事務所內部自用工具，只會存取事務所自己授權的 Gmail 信箱，不提供給外部使用者。

存取的資料

本工具透過 Google Gmail API 讀取信件內容與附件、加上處理標籤，並建立回覆草稿。本工具不會代為寄出郵件，也不會刪除郵件。

資料用途

讀取的資料只用於整理發票開立與應付款項等事務所內部作業。資料不會出售、不會用於廣告，也不會分享給第三方，但處理過程中會使用 Google Cloud 與 Google Gemini 等服務。

資料保存

處理結果僅保存在事務所自有的 Google 試算表與 Google Cloud 專案中，存取權限僅限事務所人員。

撤銷授權

可隨時到 Google 帳戶的「第三方存取權」頁面（https://myaccount.google.com/permissions）移除本工具的存取權。

Google API 使用聲明

本工具對 Google API 所取得資訊的使用與傳輸，遵守 Google API Services User Data Policy，包括 Limited Use 規定。
